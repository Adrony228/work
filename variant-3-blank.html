Задание 8 (15 баллов) — выполняется на компьютере

Разработайте программу для исполнителя «Сириус», которая методом половинного деления находит приближённый корень уравнения f(x) = x³ − 3x − 1 = 0 на отрезке [1; 2] с точностью ε = 0,001.

Вход: r1 = 1 (левая граница), r2 = 2 (правая граница), r3 = 0,001 (ε).
Выход: приближённый корень в регистре r5.

Обязательно: промежуточные значения (границы отрезка, середина, значения функции) храните в массиве памяти w[0], w[1], … — не в стеке. На каждой итерации обновляйте w[0] (левая граница), w[1] (правая), w[2] (середина), w[3] (f(середина)).
